# 实验前预测（运行前保存，另建报告解释结果）

- 问题、候选与当前协议：
- 本轮唯一核心干预；对照与不变条件：
- 主要解释的预测；根据什么证据作出预测：
- 竞争解释的不同预测：
- 能区分两种解释的读数、范围／方向与不确定性：
- 什么结果会推翻当前判断；什么结果仍然无法区分：
- 实验成功／失败／相反结果各会改变什么决定：
- 训练步数／样本数／尺度、成本上限与停止规则：

未知时明确写未知和竞争预测，不编造精确数值。将任务 JSON 的 intent_file 指向这份已填写文件；execute 在启动进程前复制归档，并随运行保存哈希。若只是回顾性导入，注明不是事前记录。不要覆盖原预测来迎合结果。

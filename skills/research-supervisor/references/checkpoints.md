# 导师判断的检查点

从 Supervisor-Skills 的选题评价、能力与资源匹配、文献核查中改编。用于研究判断；不应用上游的论文叙事、稿件评分和固定生命周期阈值。

## 研究价值与取舍

对方法改进，可以从效果、速度、鲁棒性、资源成本、适用范围检查可能的贡献。它们是不同问题入口，不是必须同时提高的五个分数。先选与研究问题相关的主轴，并约定其他量允许怎样变化；不能看完结果再切换主轴。

| 可能的贡献 | 导师要核对的证据与代价 |
| --- | --- |
| 效果提高 | 同样的可用输入、训练和合理调参条件下是否改善；是否只来自更强基础模型 |
| 速度／成本改善 | 是否维持预先指定的质量要求；训练、搜索、缓存建立和部署成本是否计入 |
| 鲁棒性／更广适用 | 是否在指定变化或新域中有效；是否增加了新的可用信息或额外标签 |
| 机制理解 | 竞争解释是否产生不同预测，干预是否区分它们，适用条件是否清楚 |
| 评测／负结果 | 是否揭示可复现的测量盲点、能力边界或已有解释的问题；是否排除实现错误 |

评测或负结果不必附带一个新模型。纯调参也可以有工程价值，但要说明它新增了什么研究认识，不能仅因分数最高就称为机制创新。

## 查新与文献盲点

对支持当前方向的工作、反例和批评、相邻机制、评测方法分别查缺口，沿最接近工作的引用关系补查。先核对文献身份，再核对它是否支持当前句子；机制、数值与具体条件需要相应原文，检索摘要不能代替。

检索记录说明查过哪些词、打开哪些原文、还有哪些缺口。尚未查到重合工作只是一项检索结果。基线是否合适看任务、访问条件与方法强度，也需检查最新相关进展；不能仅凭论文超过一年就判它无效。多视角检索可以由同一 Agent 顺序完成，不要求堆数量或开启多个 Agent。

## 资源与完成路径

用当前实现进展、短运行成本、数据准备难度和用户已有资源估计下一步；区分“下一个可判别实验”和“完成主张所需的全部确认”。给估计依据与不确定性，预留失败、复测和确认预算。没有测量时先跑成本探针。

研究竞争和新论文可能改变问题的重要性，需要按实际进展复查。不要把方向类别映射到固定到期月份，也不把周工时、GPU 张数当成能否做科研的统一门槛。资源不匹配时优先收窄问题或贡献范围；不能削弱基线与评测来迁就预算。

## 典型情况下怎样指导

以下是判断情境，不是本项目已经得到的实验结果。

| 当前情境 | 导师应给出的下一步 |
| --- | --- |
| 点子逻辑顺，但没有实测 | 找最可能推翻它的便宜实验；保留为假设，不宣布录用潜力已获证明 |
| 一次短运行落后 | 核对执行、训练是否充分、波动与原预测；若不足以判别，补特定对照，不自动否定整个方向 |
| 可靠对照否定核心解释 | 放弃或修订被反驳的主张，保留负结果；若有新问题，另立假设，不能换指标挽救原结论 |
| 原始数值较好，但来源可能是额外数据 | 先匹配信息来源并做对照，暂不把改善归因于新模块 |
| 正式实验很贵，基线或评测未通过 | 优先修复验收问题，不因“导师看好”扩大算力 |
| 多轮只重复微调超参 | 核对搜索历史与新增认识，选择一个竞争解释或停止探索，不把运行数量当研究进度 |
| 总分持平，但有可复现机制或成本发现 | 按原定问题评价发现；允许负结果或范围明确的贡献，不强求全面胜出 |

每次指导结束时只推进最优先的下一项行动；还没解决的问题保留在原记录，不随报告缩短而消失。

# 评的是证据成熟度，不是论文录用概率

这个量表是本项目的内部讨论工具，不是 ICML 官方评分表。可借目标会议的评审维度提问；投稿年份／track 确定后查当年的官方标准。新颖性要比较原文，技术可靠性要看实验，意义要联系实际问题。写作和 presentation 的评价留到论文阶段。

## 用相同尺度记录，逐项给依据

每项可填 0–3 或 unknown：0 表示当前证据反对／不可行；1 表示有合理论据但关键证据缺失；2 表示已有相关证据支持继续检验；3 表示关键证据较充分且主要竞争解释得到检查。unknown 表示尚未核查。分值是顺序标签，不求平均、不加权得“录用分”，不因某一项高就盖过另一项的缺口。

| 维度 | 需要的证据 | 应优先处理的缺口 |
| --- | --- | --- |
| 问题价值 | 可复现失效、受影响范围、实际成本或认识上的缺口 | 只因热门、观察影响极小、简单修复已解决 |
| 近邻差异 | 具体论文／代码位置与逐项差别 | 已有工作覆盖、只改名称、关键原文未读 |
| 机制与可检验性 | 竞争解释、不同预测、干预与反证条件 | 只能观察总分、任何结果都能圆回来 |
| 证据可靠性 | 合理基线、有效评测、真实运行和不确定性 | 欠调基线、泄漏、任务无分辨力、挑最好结果 |
| 可完成性 | 实现条件、最小判别成本和完整确认成本 | 预算只够探索、关键数据不可得、主张需要未具备规模 |

“未知”触发阅读或短实验；0 不一定意味着方向永远无价值，可以缩小问题，但必须留下原判断。暂时不满足完整确认条件的机制观察，可作为探索结果保留，不能升级为普遍结论。

## 固定三种有用追问

- **依据**：这句话来自哪个运行、哪篇论文，还是未验证推测？只给原始出处与相关读数，别重复整段故事。
- **竞争解释**：如果收益仅来自学习率、训练量、容量、标签或捷径，这个实验会得到什么结果？
- **决定**：这个结果会让我继续、修改、停止还是扩大？若无论结果如何都会继续，先改实验。

审查时优先读取原始设定、方法差异和全部结果，避免先让生成点子的 Agent 给自己的方案贴“优秀”标签。模型分歧是待核实的问题清单，不是投票裁决。
